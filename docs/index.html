ระบบใบขออนุญาตปฏิบัติงานออนไลน์ · FM-MR-58

ขอ Work Permit
ง่าย รวดเร็ว ปลอดภัย

ผู้รับเหมาและหน่วยงานภายใน กรอกใบขออนุญาตปฏิบัติงาน ลงลายมือชื่อออนไลน์ แล้วส่งตรงถึง เจ้าหน้าที่ความปลอดภัย (จป.) เพื่อตรวจสอบและอนุมัติแบบเรียลไทม์

ขั้นตอนการขอใบอนุญาต

1. กรอกข้อมูล

ระบุประเภทงาน ลักษณะงาน วันเวลา สถานที่ และรายชื่อพนักงานที่เข้าปฏิบัติงาน

2. ตรวจสอบความพร้อม

เช็คลิสต์ความปลอดภัยตามลักษณะงาน พร้อมอุปกรณ์ PPE ที่ต้องใช้

3. ลงนามออนไลน์

ยอมรับระเบียบความปลอดภัย และเซ็นชื่อผู้ขออนุญาตบนหน้าจอได้ทันที

4. จป. อนุมัติ

จป. ได้รับแจ้งเตือนทันที ตรวจสอบ อนุมัติ และพิมพ์ใบอนุญาตได้
